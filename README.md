One museum label, 129 characters, for the year 3000: "Wall sign, c. 2023. Sacred household text commanding its owners to live, laugh and love. Displayed in every home, obeyed in none." The curators of the future misread a "live, laugh, love" wall sign as a sacred commandment — and the punchline is that nobody obeyed it. The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
